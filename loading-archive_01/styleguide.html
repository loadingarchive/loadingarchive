Style Guide

Internal reference, not linked from the site. Every color, type size and component below is pulled from /css/site.css, the single stylesheet loaded by every page (homepage, game pages, month pages, trending, about, privacy, contact). Edit a value there and it updates everywhere at once. Page-specific layout (hero, carousels, forms, filters) stays local to each page's own template.
